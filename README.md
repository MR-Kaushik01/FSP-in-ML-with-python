## About
Solutions to 10 machine learning exercises using Python, pandas,
scikit-learn, matplotlib and seaborn, written in a Jupyter notebook
(`FSP_ML_with_Python.ipynb`).

## Questions Covered

| Q | Topic |
|---|-------|
| 1 | 70/30 train-test split and standard scaling |
| 2 | Outlier visualisation using boxplot and scatter plot |
| 3 | Linear regression on housing data (RMSE, MAE, R²) |
| 4 | Logistic regression on Iris, predicted classes |
| 5 | KNN (k=5) and confusion matrix |
| 6 | Decision Tree vs Random Forest comparison |
| 7 | Precision, recall and F1-score for a specific class |
| 8 | 5-fold cross-validation of Ridge regression |
| 9 | GridSearchCV for Random Forest hyperparameters |
| 10 | Pipeline with MinMaxScaler and Logistic Regression |

## Datasets
Built-in scikit-learn datasets: Wine, California Housing, Iris, Breast Cancer and Diabetes.
